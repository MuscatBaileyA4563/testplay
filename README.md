# ブロック崩しde足トレ（運動療法用ブロック崩し）

ビルド不要の静的ファイル一式です。`index.html` / `sw.js` / `manifest.webmanifest` / アイコン3点を
同じフォルダに置いて配信すればそのまま動きます（相対パス構成のため GitHub Pages のサブディレクトリでも可）。

## 動かす

```bash
# ローカル確認（PWA と カメラは https か localhost が必須）
python3 -m http.server 8080
# → http://localhost:8080
```

公開する場合は HTTPS 必須です（getUserMedia と Service Worker の要件）。

## 今回の変更点

| 要望 | 実装 |
| --- | --- |
| BGM・効果音 | Web Audio でリアルタイム合成（音源ファイル不要＝オフラインでも鳴る）。BGM は 128BPM・8セクション約2分のエレクトロ構成（イントロ→Aメロ→Bメロ→サビ→間奏→Bメロ→サビ→アウトロ）をループ。キックに合わせたサイドチェインとディレイ付き |
| ボールの視認性 | カメラ映像に blur + 減光の CSS フィルタ、描画側に暗幕（0〜85%可変）とビネット、ボールに軌跡・ハロー・暗い縁取り |
| 認識範囲は据え置き | 検出は `<video>` の生フレームを直接 GPU に転送。画面の暗幕・CSSフィルタは検出に一切影響しません。範囲も従来どおり映像下部約30% |
| GPU 活用 | 描画を WebGL2 のバッチレンダラに変更（`shadowBlur` 等の CPU 描画を廃止）。フレーム間差分もフラグメントシェーダで計算し、読み戻しは 64×15 px のみ |
| 記録 | localStorage にプレイ日時・運動時間・ポイント・レベルを保存し、ポイント順で上位5件を自動登録 |
| ボールの速さ | L（×0.78）／N（×1.00）／H（×1.25）の3段階。初期値は N で、表示倍率も N を基準にしています（H が従来と同じ速度）。設定画面のほか、プレイ中はカメラ切替の隣のボタンで切り替えでき、飛んでいるボールの速度にも即座に反映されます |
| 難易度 | 10段階。ブロック耐久1〜3、破壊不能ブロック、レベルごとに別レイアウト、ボール速度とバー幅も段階変化 |
| PWA | manifest + Service Worker。ホーム画面に追加、オフライン起動可 |

WebGL2 が使えない端末では Canvas 2D と CPU 差分に自動フォールバックします。
カメラが使えない場合は矢印キー／画面タッチで操作できます（動作確認用）。


## 操作方法の変更（キック操作）

仰臥位で「足を横にずらす」動きが出てしまう問題への対策として、既定の操作を **キック操作** に変更しました。

| | キック（既定） | よこ（従来） |
| --- | --- | --- |
| 拾う動き | 判定ラインより **上** に出た動きだけ | 下部31%の動きの左右位置 |
| バーの動き | 上げた側へ押し出す**速度制御**（足を止めると止まる） | 動いた位置へ**追従**（絶対位置） |
| 横ぶり | 入力にならない（ラインより下は無視） | そのまま入力になる |

- みぎ足を蹴り上げる → バーがみぎへ、ひだり足 → ひだりへ。上げっぱなしでは進まないので、**交互の膝上げが最短ルート**になります。
- 蹴り上げの立ち上がりを検出して、キック音・インパルス（初速）・粒子を出します。落下中のボールが近いタイミングだと「ナイスキック！」＋20ポイント。
- ラインより下の動きだけが続くと「よこに振らず、ひざを上げて！」と表示します。
- 検出範囲は下部31%→**下部62%**に拡張（膝上げの可動域を含めるため）。読み戻しは 64×30 px。
- 設定：`操作のしかた` / `足上げの高さ`（判定ラインの位置）/ `アシスト`（足を止めるとバーがボールへ寄る）/ `足と画面の左右を入れかえる`。
- 中断（⏸）画面では **足を動かしながらライブのゲージを見て** しきい値を調整できます。
- 従来の操作は設定で「よこ」を選べば元どおりです。

## BGM について

`SONG` / `CHORD_ROOTS` / `CHORD_NOTES` / `CHORUS_MEL` の4つのデータでできています。
`SONG` の各セクション名（イントロ／Aメロ／Bメロ／サビ／間奏／アウトロ）が `Sound.scheduleStep()` の分岐に対応するので、
セクションの小節数を変えれば構成を、`CHORD_*` を変えればコード進行を差し替えられます。16分音符きざみのスケジューラで、
先読み 120ms・25ms 間隔で発音を予約しているためタイミングは安定します。

BGMはステージをまたいで途切れず続き、メニューに戻ったときだけ先頭に巻き戻ります。

## ステージの進行

クリア時もゲームオーバー時も、5秒のカウントダウン後に自動で続きが始まります。

- Lv1〜9 をクリア → 次のレベルへ。ポイント・うんどう時間・のこり残機をすべて引き継ぎます
- ゲームオーバー → 同じレベルをやり直し。ポイントとうんどう時間は引き継ぎ、のこりだけ 5 に戻ります
- Lv10 クリア／中断画面から「やめて記録する」を選んだとき → 自動継続しません

カウント中も「いますぐ進む（再開する）」「はじめから」「メニューにもどる」は操作でき、押した時点で
カウントは止まります。記録は1セッション1件だけ、最終到達時点の内容で登録されます。
